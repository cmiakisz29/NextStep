# NextStep

A mobile-friendly MVP that turns a user's goal into an actionable roadmap.

## Run it
Open `index.html` in any modern browser. No server or account is required.

## Included
- Responsive landing page
- Goal intake form
- Roadmaps for career, business, learning, school, personal projects, and general goals
- Progress checkboxes
- Local browser saving with localStorage
- Mobile layout
- Basic safety disclaimer

## Important
This is an MVP. The plan generator currently uses curated templates rather than an AI API, so it works without API keys or hosting infrastructure.
